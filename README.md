# CNet-Suite-Library
The C Network Suite Library
Pure C library (50+ API modules) covering everything a native application typically needs on Windows (zero dependencies), Linux, or macOS (needs openSSL, zlib, unixODBC, ICU, CUPS packages on target machine): collections, LINQ and concurrency, cryptography and TLS, sockets, most popular ODBC databases, file/process/serial/printer I/O, JSON/XML/Regex, and a signed license-gating system, all fully Unicode compliant end to end, from file paths to database.
